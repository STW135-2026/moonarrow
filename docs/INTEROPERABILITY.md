# Interoperability contract

MoonArrow treats cross-language fixtures as executable format contracts rather
than as examples generated by its own code.

## Current fixture

`fixtures/pyarrow-basic.arrows` is produced by PyArrow 25.0.1 through
`tools/generate_fixtures.py`. It contains one record batch with four flat Arrow
types:

| Field | Arrow type | Nullable | Values |
| --- | --- | --- | --- |
| `city` | UTF-8 | no | Shenzhen, Paris, Unknown, Tokyo |
| `temperature_c` | Int32 | yes | 31, 19, null, 27 |
| `active` | Boolean | yes | true, null, false, true |
| `score` | Float64 | yes | 9.5, null, -1.25, 7.0 |

The native integration test reads the committed binary through the filesystem
and verifies the schema and every value. The remaining parser and array tests
run on all supported MoonBit targets.

## Regenerating

Install the pinned development dependency and regenerate from the repository
root:

```bash
python -m pip install -r requirements-dev.txt
python tools/generate_fixtures.py
moon test --target all
```

Any fixture change should be reviewed together with its generator change. A
binary produced by MoonArrow itself must not replace the independent PyArrow
fixture.

## Supported reader surface

- IPC stream envelopes with current continuation markers or legacy prefixes
- Metadata versions V1 through V5
- Little-endian, flat schemas
- Signed 32-bit integer, double precision float, bit-packed Boolean, and UTF-8
- Any number of record-batch messages sharing the stream schema

Explicitly rejected today: dictionary encoding, nested fields, big-endian
schemas, compression, unsupported primitive widths, IPC files, and tensors.
