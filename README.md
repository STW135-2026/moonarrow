# MoonArrow

[![CI](https://github.com/STW135-2026/moonarrow/actions/workflows/ci.yml/badge.svg)](https://github.com/STW135-2026/moonarrow/actions/workflows/ci.yml)

Apache Arrow-compatible columnar memory, IPC, and DataFrame primitives written
in MoonBit. MoonArrow can already read real PyArrow IPC streams and run the same
in-memory compute core on native, JavaScript, WebAssembly, and WasmGC targets.

## Implemented

- Ordered schemas with unique field names and nullability contracts
- Arrow-compatible LSB-first bitmaps
- Nullable `Boolean`, `Int32`, `Int64`, `Float64`, `Utf8`, and `Binary` arrays
- Record-batch validation
- Filter, take, scalar comparison, sum, mean, and min/max kernels
- Eager DataFrame projection, filtering, limiting, and aggregation
- Bounds-checked FlatBuffers metadata reader
- Arrow IPC stream framing and schema/record-batch decoding
- Cross-language fixture generated by PyArrow 25
- Runnable IPC inspector with row previews and multi-target CI

The MVP is complete and reproducible. See the
[MVP acceptance checklist](docs/MVP-CHECKLIST.zh-CN.md) for the exact commands,
scope, and evidence expected during review.

## Run

```bash
moon update
moon check --target all
moon test --target all
moon run cmd/main
moon run cmd/ipc_inspect --target native
```

Expected demo output:

```text
MoonArrow DataFrame demo
rows: 4
temperature sum: 77
temperature mean: 25.666666666666668
warm rows: 2
```

The IPC inspector reads `fixtures/pyarrow-basic.arrows` by default, or accepts
another Arrow stream path:

```bash
moon run cmd/ipc_inspect --target native -- path/to/data.arrows
```

## Packages

| Package | Responsibility |
| --- | --- |
| `src/types` | Logical types, fields, and schemas |
| `src/bitmap` | Packed validity/value bitmaps |
| `src/array` | Physical nullable column arrays |
| `src/compute` | Columnar compute kernels |
| `src/record_batch` | Typed multi-column batches |
| `src/dataframe` | Eager tabular query facade |
| `src/flatbuffer` | Bounds-checked FlatBuffers reader |
| `src/ipc` | Arrow stream, schema, and record-batch decoder |

See [architecture](docs/ARCHITECTURE.md), [roadmap](docs/ROADMAP.md),
[development log](docs/DEVELOPMENT_LOG.zh-CN.md), [changelog](CHANGELOG.md), and
the [Chinese proposal](docs/PROPOSAL.zh-CN.md).

## Status and scope

Version `0.1.0` is an MVP and its public API may evolve. IPC reading currently
supports flat `Boolean`, `Int32`, `Int64`, `Float64`, `Utf8`, and `Binary`
fields. Dictionary arrays, nested arrays, compression, IPC file containers, and
writing are explicit future work. Malformed lengths, offsets, FlatBuffers
tables, validity buffers, and UTF-8 are rejected with structured errors.
